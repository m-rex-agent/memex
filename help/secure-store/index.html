Linux · bulut depoları

Sisteminin parola deposunu aç

memex’te “Bulut depoları bu sistemde kullanılamıyor” uyarısını görüyorsan sisteminde çalışan bir parola deposu yok. memex, bulut bağlantı bilgilerini bu depoda saklar; sen bir parola deposu başlatana kadar bulut depoları kullanılamaz. Bir dakikalık iş.

GNOME, Ubuntu, Fedora Workstation

  • Parola deposu sistemle birlikte gelir. Kurulu ve çalışır durumda olduğundan emin ol: sudo apt install gnome-keyring (Fedora: sudo dnf install gnome-keyring). Sonra oturumu kapatıp yeniden aç.

KDE Plasma

  • Sistem Ayarları’nı aç, “KDE Wallet” (KDE Cüzdanı) bölümüne git ve “Enable the KDE wallet subsystem” (KDE cüzdan alt sistemini etkinleştir) seçeneğini işaretle; “Secret Service” seçeneği de görünüyorsa onu da aç. Bölüm yoksa önce kwalletmanager paketini kur (sudo apt install kwalletmanager). Sonra oturumu kapatıp yeniden aç.

i3

  • gnome-keyring paketini kur, şu satırı ~/.config/i3/config dosyasına ekle ve oturumu kapatıp yeniden aç (i3’ü yeniden başlatmak bu satırı çalıştırmaz):
    exec --no-startup-id gnome-keyring-daemon --start --components=secrets

Sway

  • gnome-keyring paketini kur, şu satırı ~/.config/sway/config dosyasına ekle ve oturumu kapatıp yeniden aç (yapılandırmayı yenilemek bu satırı çalıştırmaz):
    exec gnome-keyring-daemon --start --components=secrets
    Bazı kurulumlar bu hizmeti zaten başlatır; seninki başlatıyorsa bu satıra gerek yok.

Hyprland

  • gnome-keyring paketini kur, şu satırı ~/.config/hypr/hyprland.conf dosyasına ekle ve oturumu kapatıp yeniden aç:
    exec-once = gnome-keyring-daemon --start --components=secrets
    Bazı kurulumlar bu hizmeti zaten başlatır; seninki başlatıyorsa bu satıra gerek yok.

KeePassXC

  • Çalışan başka bir parola deposu varsa önce onu kapat. Sonra Araçlar → Ayarlar → Gizli hizmet bütünleşmesi bölümünü aç ve “KeepassXC Freedesktop.org gizli hizmet bütünleşmesi kullanılsın” seçeneğini işaretle. Ardından veri tabanını aç, Veri tabanı → Veri tabanı ayarları → Gizli hizmet bütünleşmesi bölümüne git ve “Bu grubun altındaki kayıtları açığa çıkart” alanından bir grup seç.

Sonra

  1. memex’e dön ve “Yeniden dene”ye tıkla.
  2. Bulut depoları hâlâ kullanılamıyorsa Sorun bildir ve uygulamanın gösterdiği ayrıntıları ekle.

Linux · cloud storage

Turn on your system’s password store

memex keeps your cloud connection details in your system’s password store. Your system has none running, so cloud storage is unavailable until you start one. It takes a minute.

GNOME, Ubuntu, Fedora Workstation

  • The password store is built in. Make sure it is installed and running: sudo apt install gnome-keyring (Fedora: sudo dnf install gnome-keyring), then log out and back in.

KDE Plasma

  • Open System Settings, go to KDE Wallet, and turn on “Enable the KDE wallet subsystem” (and the Secret Service option if it is shown). If the section is missing, install kwalletmanager first (sudo apt install kwalletmanager). Log out and back in.

i3

  • Install gnome-keyring, then add this line to ~/.config/i3/config and log out and back in (restarting i3 does not run it):
    exec --no-startup-id gnome-keyring-daemon --start --components=secrets

Sway

  • Install gnome-keyring, then add this line to ~/.config/sway/config and log out and back in (reloading the config does not run it):
    exec gnome-keyring-daemon --start --components=secrets
    Some setups already start this service; if yours does, the line is not needed.

Hyprland

  • Install gnome-keyring, then add this line to ~/.config/hypr/hyprland.conf and log out and back in:
    exec-once = gnome-keyring-daemon --start --components=secrets
    Some setups already start this service; if yours does, the line is not needed.

KeePassXC

  • Open Tools → Settings → Secret Service Integration and turn on “Enable KeePassXC Freedesktop.org Secret Service integration”. Then open your database, go to Database → Database Settings → Secret Service Integration, and expose a group. Stop any other password store first.

Then

  1. Go back to memex and click “Yeniden dene” (Try again) after doing the steps.
  2. Still unavailable? Report it and include the details the app shows.
